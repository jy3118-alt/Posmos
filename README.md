# Posmos

예술가 Po와 친구들이 사는 2.5D 섬입니다. 현재 버전은 world-v103입니다.
현재 운영 세계를 유지하면서 육지 직접 조종과 Blender에서 다듬은 Po 8종(수영용 포함)을 적용했습니다.
모든 모델은 공유 GLB/관절 애니메이션과 거리별 LOD를 사용하며, 캐릭터 텍스처는 1024px입니다.
드레스 Po의 얼굴·어깨 연결과 웨이트를 수정하고 기존 치마 동작을 유지했습니다.

운영 주소: https://posmos-beryl.vercel.app/

- 최신 운영 중인 마을·겨울 섬·수중 지형·물고기·바람·동상 반사를 유지합니다.
- Po 150명, 드레스 Po 1명, Moa 1명. 서로 만나 추상화를 그리고 작품을 PNG/SVG로 저장할 수 있습니다.
- 육지에서는 한 캐릭터를 직접 조종합니다. W/A/S/D 또는 방향키로 이동, Shift로 달립니다.
- 화면을 누른 채 드래그하면 앞으로 움직이며 방향을 바꿉니다. 오른쪽 드래그는 시점만 바꿉니다.
- Tab은 대체로 65m 이상 떨어진 다른 캐릭터를 무작위로 고릅니다. 최근 선택은 가능한 한 피합니다.
- 다른 캐릭터를 짧게 클릭해 직접 선택할 수도 있습니다. 수영 중이거나 그림을 그리는 친구는 현재 선택 대상에서 제외합니다.
- 휠 또는 두 손가락 벌리기로 확대/축소. 모바일 두 손가락 짧은 탭으로도 캐릭터 전환.
- Escape로 자유 시점, 캔버스에서 Tab으로 다시 조종. Shift+Tab은 일반 접근성 탐색을 유지합니다.
- 선택을 떠난 친구는 현재 자리에서 새로운 안전 경로로 자율 이동하며 원래 위치로 순간 이동하지 않습니다.
- 상단 아이콘: 아침 / 노을 / 밤. 시간은 자동으로도 흐릅니다.
- 기존 시간대 아이콘과 수중 진입 아이콘을 유지하며 새 조작 UI는 추가하지 않습니다. 소리는 없습니다.
- 수중 진입 시 육지 조종은 해제되고, 육지 복귀 시 다시 연결됩니다. 그림 확대와 PNG/SVG 저장은 유지합니다.

## 실행

Node.js 22 이상에서: `node scripts/preview.mjs`

http://127.0.0.1:4181/Posmos/ 를 여세요.

## 배포

main에 push하면 연결된 Vercel 프로젝트가 자동 배포합니다.
정적 파일만 배포하며, 별도 설치·빌드·환경 변수·Tripo API 키는 필요하지 않습니다.
GitHub Pages는 수동 백업입니다. Actions의 Manual GitHub Pages backup으로만 갱신합니다.

site는 최신 운영본과 새 조작 모듈을 포함합니다. 이전 릴리스 파일도 보존되어 있으나 진입 파일에서 참조하지 않으면 로드하지 않습니다.
Blender 원본, 생성 영수증, 인증 파일과 개발 백업은 포함하지 않습니다.
모듈·워커·모델 의존 파일에는 내용 기반 버전을 붙여 이전 캐시와 섞이지 않게 합니다.
