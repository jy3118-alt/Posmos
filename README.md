# Posmos

예술가 Po와 친구들이 사는 2.5D 섬입니다. 현재 운영 버전은 district-v71입니다.

운영 주소: https://posmos-beryl.vercel.app/

- 높낮이가 다른 여섯 구역, 강·호수·숲·예술 정원과 세 개의 공중 섬.
- 블렌더에서 조형한 물감 섬과 서로 다른 흰 물감 구름 일곱 개. 뒤집힌 정원의 Po 세 명은 거꾸로 걸어 다닙니다.
- Po 150명, 드레스 Po 1명, Moa 1명. 서로 만나 추상화를 그리고 작품을 PNG/SVG로 저장할 수 있습니다.
- 캐릭터 클릭: 따라가기. 같은 캐릭터를 다시 클릭: 추적 해제.
- 드래그: 회전. 오른쪽 드래그: 이동. 휠: 확대/축소.
- 상단 아이콘: 아침 / 노을 / 밤. 시간은 자동으로도 흐릅니다.
- 제목·아래 위치 버튼·안내 문구 없이 시간대 아이콘만 표시합니다. 소리는 없습니다.
- 섬에 숨겨진 Po 그림 세 점을 찾아 누르면 크게 보고 PNG/SVG로 저장할 수 있습니다.

## 실행

Node.js 22 이상에서: `node scripts/preview.mjs`

http://127.0.0.1:4181/Posmos/ 를 여세요.

## 배포

main에 push하면 연결된 Vercel 프로젝트가 자동 배포합니다.
정적 파일만 배포하며, 별도 설치·빌드·환경 변수·Tripo API 키는 필요하지 않습니다.
GitHub Pages는 수동 백업입니다. Actions의 Manual GitHub Pages backup으로만 갱신합니다.

site에는 현재 실행에 필요한 파일만 있습니다. Blender 원본, 생성 영수증, 인증 파일과 개발 백업은 포함하지 않습니다.
모듈·워커·모델 의존 파일에는 내용 기반 버전을 붙여 이전 캐시와 섞이지 않게 합니다.
